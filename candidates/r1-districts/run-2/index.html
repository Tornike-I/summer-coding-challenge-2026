Districts

Teal is outnumbered. Draw the map anyway — fewest votes, most seats.

Two invented colours on an abstract council. Progress is saved on this device when the browser allows it.

How to play

1

Start a district

Click, tap or press Enter on any free cell. That opens district 1.

2

Keep it joined

Drag to paint. You may only add cells touching the district you are drawing, so it can never break apart. It locks at its exact size and the next one opens.

3
3–1

Win the seats, not the votes

Whoever holds more cells in a district takes that seat. An even split is a tie and counts for nobody. Take more seats than Amber and the level is passed.

Teal is a solid dot. Amber is a ring. Shape as well as colour, so the board reads either way.
